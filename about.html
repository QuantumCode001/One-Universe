About This App

This application is built with a premium glassmorphism UI concept, focusing on modern design, smooth interactions, and a clean user experience.

Purpose

The goal of this project is to demonstrate front-end UI skills using HTML, CSS, and JavaScript while maintaining a professional, app-like look. It is designed for learning, showcasing, and experimentation.

Technology Used

• HTML5 for structure
• CSS3 for glass effects, animations, and responsiveness
• JavaScript for theme switching and interactions
